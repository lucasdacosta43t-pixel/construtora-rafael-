# Site do Eletricista Celso

## Como usar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador para visualizar o site.
3. Para publicar, envie a pasta para sua hospedagem (ou publique no GitHub Pages, Netlify, Vercel etc.).

## Dados configurados

- Instagram: @celsof.eletricista
- Formulário: monta automaticamente a mensagem e abre o WhatsApp.
